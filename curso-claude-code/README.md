# Curso Básico de Claude Code

Bienvenido al curso básico de Claude Code. Este curso te guiará paso a paso desde la instalación de WSL en Windows hasta la creación de tu primer proyecto con Claude Code.

## 📋 Descripción del Curso

Este curso está diseñado para principiantes que desean aprender a usar Claude Code, una herramienta de IA conversacional para desarrollo de software. Aprenderás a configurar tu entorno de desarrollo, instalar Claude Code y trabajar en proyectos reales con asistencia de IA.

## 🎯 Objetivos de Aprendizaje

Al finalizar este curso, serás capaz de:
- Instalar y configurar WSL en Windows
- Instalar y configurar Claude Code
- Iniciar y gestionar proyectos con Claude Code
- Desarrollar aplicaciones básicas con asistencia de IA
- Aplicar mejores prácticas en el uso de Claude Code

## 🛠️ Requisitos Previos

- **Sistema Operativo**: Windows 10 versión 2004 o superior (Build 19041 o superior) o Windows 11
- **Hardware**:
  - 4 GB de RAM mínimo (8 GB recomendado)
  - 10 GB de espacio en disco
- **Conexión a Internet**: Para descargar componentes y usar Claude Code
- **Cuenta de Anthropic**: Para obtener tu API Key (se explicará en el curso)

## 🚀 Cómo Usar Este Curso

1. **Sigue el orden**: Los módulos están diseñados para seguirse secuencialmente
2. **Practica**: Ejecuta todos los comandos y ejemplos en tu propia máquina
3. **Experimenta**: Prueba variaciones de los ejemplos proporcionados
4. **Consulta**: Si tienes dudas, revisa la sección de solución de problemas de cada módulo
